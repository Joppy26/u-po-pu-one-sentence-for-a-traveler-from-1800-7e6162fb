One sentence, at most 200 characters, explaining the modern internet to a
time traveler who has just stepped out of the year 1800. It builds only from
things a person from 1800 already knows: a road, a post office, a library,
and a market stall.

## Entry

> Imagine every library, post office, and market stall in the world joined by one road, so any letter, book, picture, or song reaches anyone in a blink.

## Run

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` (150 characters, one sentence,
no trailing newline). The program is deterministic: it writes the same fixed
text on every run.
